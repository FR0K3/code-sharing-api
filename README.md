# Code Sharing API

REST API for sharing code snippets. Lets you create a snippet and retrieve it later through a unique identifier.

Built with **Express 5**, **TypeScript**, **Kysely** (PostgreSQL) and **Zod** for validation.

---

## Requirements

- Node.js 20+
- PostgreSQL

## Installation

```bash
npm install
```

Create a `.env` file in the project root:

```env
DATABASE_URL=postgres://user:password@localhost:5432/code_sharing
PORT=4000
```

| Variable       | Required | Default | Description                       |
| -------------- | :------: | ------- | --------------------------------- |
| `DATABASE_URL` |   Yes    | —       | PostgreSQL connection string.     |
| `PORT`         |    No    | `4000`  | Port the server listens on.       |

## Database

The API expects a `snippets` table with the following structure:

```sql
CREATE TABLE snippets (
  id       TEXT PRIMARY KEY,
  code     TEXT NOT NULL,
  language TEXT NOT NULL DEFAULT 'plaintext',
  theme    TEXT NOT NULL DEFAULT 'vs-dark'
);
```

Database TypeScript types are generated with `kysely-codegen` into [src/db.d.ts](src/db.d.ts) (do not edit by hand).

## Running

```bash
npm run dev
```

The server starts at `http://localhost:4000`.

## Endpoints

All routes live under the `/api/snippets` prefix.

### `POST /api/snippets`

Creates a new snippet.

**Body** (`application/json`)

| Field      | Type     | Required | Default       | Constraints            |
| ---------- | -------- | :------: | ------------- | ---------------------- |
| `code`     | `string` |   Yes    | —             | 1 to 100,000 characters |
| `language` | `string` |    No    | `"plaintext"` | at least 1 character   |
| `theme`    | `string` |    No    | `"vs-dark"`   | at least 1 character   |

**Example**

```bash
curl -X POST http://localhost:4000/api/snippets \
  -H "Content-Type: application/json" \
  -d '{
    "code": "console.log(\"Hello world\");",
    "language": "javascript",
    "theme": "vs-dark"
  }'
```

**`201 Created`**

```json
{
  "id": "V1StGXR8_Z5jdHi6B-myT",
  "code": "console.log(\"Hello world\");",
  "language": "javascript",
  "theme": "vs-dark"
}
```

**`400 Bad Request`** — the body fails validation:

```json
{
  "message": "Data not valid",
  "errors": [
    { "field": "code", "message": "Code cannot be empty" }
  ]
}
```

---

### `GET /api/snippets/:id`

Retrieves a snippet by its `id`.

**Path parameters**

| Parameter | Type     | Constraints                       |
| --------- | -------- | --------------------------------- |
| `id`      | `string` | Exactly 21 characters (nanoid)    |

**Example**

```bash
curl http://localhost:4000/api/snippets/V1StGXR8_Z5jdHi6B-myT
```

**`200 OK`**

```json
{
  "id": "V1StGXR8_Z5jdHi6B-myT",
  "code": "console.log(\"Hello world\");",
  "language": "javascript",
  "theme": "vs-dark"
}
```

**`404 Not Found`**

```json
{ "message": "Snippet not found" }
```

**`400 Bad Request`** — the `id` is not 21 characters long:

```json
{
  "message": "Data not valid",
  "errors": [
    { "field": "id", "message": "Too small: expected string to have >=21 characters" }
  ]
}
```

## Project structure

```
src/
├── config/
│   └── db.ts               # PostgreSQL connection (Kysely + pg Pool)
├── middleware/
│   └── validate.ts         # Generic Zod validation middleware
├── routes/
│   └── snippetsRoutes.ts   # Snippet endpoints
├── schemas/
│   └── snippet.ts          # Zod schemas
├── db.d.ts                 # Types generated by kysely-codegen
├── server.ts               # Express app setup
└── index.ts                # Entry point (listen)
```

## Notes

- Identifiers are generated with `nanoid` (21 characters, URL-safe).
- The [validate.ts](src/middleware/validate.ts) middleware replaces `req[source]` with the parsed data, so Zod defaults (`language`, `theme`) are applied automatically.
